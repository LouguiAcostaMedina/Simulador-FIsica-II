# Manual de Usuario

**Navegación**: Utilice el Hub principal para seleccionar el módulo deseado.
**Módulo U1**: Inserte cargas definiendo Q y posición, y haga clic en "Añadir". Puede interactuar visualmente en 2D y 3D.
**Módulo U2**: Ajuste el área, distancia y material (er) usando los campos numéricos. Seleccione el modo de la batería para observar el comportamiento al introducir un dieléctrico. Utilice "Fijar Escenario" para comparar.
