# Manual de Usuario

**Navegación**: Utilice el Hub principal para seleccionar el módulo deseado.

**Módulo U1 (Eléctrico)**:
- Inserte cargas definiendo Q y posición, y haga clic en "Añadir".
- Utilice "Preset Dipolo" para añadir rápidamente un arreglo simétrico.
- En la vista 3D puede visualizar las superficies equipotenciales.
- Si WebGL falla, el simulador avisará y cambiará a la vista 2D de forma segura.

**Módulo U2 (Capacitores)**:
- Ajuste el área $A$, distancia $d$ y material $\varepsilon_r$ usando los campos numéricos. 
- Seleccione el modo de la batería para observar el comportamiento al introducir un dieléctrico. 
- Utilice "Fijar Escenario" para comparar.
- Las gráficas se actualizan en tiempo real interactuando con los controles.

**Módulo U3 (Corriente y Ohm)**:
- En la pestaña "Ohm y Circuitos", haga clic en los botones "+" para añadir resistencias en serie o en paralelo, construyendo arreglos mixtos recursivos. La resistencia equivalente y corriente total se calculan instantáneamente.
- En la pestaña "Circuito RC", defina los parámetros para observar en la gráfica las curvas de carga y descarga exponencial del capacitor en tiempo real.

**Módulo U4 (Magnetismo)**:
- Elija entre el modelo de un conductor rectilíneo largo (donde $B \propto 1/r$) o un dipolo magnético.
- Active la "Fuerza de Lorentz" lanzando una partícula de prueba. Ajuste $v_z$ inicial y un Campo Eléctrico externo en el eje Y ($E_y$) para estudiar la conservación del movimiento rectilíneo y la deriva (selector de velocidades).
