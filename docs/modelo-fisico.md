# Modelo Físico

**Unidad 1**
- Campo Eléctrico: $E(r) = k \sum \frac{q_i(r-r_i)}{|r-r_i|^3}$
- Potencial: $V(r) = k \sum \frac{q_i}{|r-r_i|}$
- Fuerza: $F = q_t E$
- Aceleración: $a = \frac{F}{m}$
- Integración: Euler-Cromer simple

**Unidad 2**
- Capacitancia: $C = \frac{\varepsilon_0 \varepsilon_r A}{d}$
- Carga: $Q = CV$
- Energía: $U = \frac{1}{2} C V^2$
- Campo: $E = \frac{V}{d}$ (idealizado sin efectos de borde)
